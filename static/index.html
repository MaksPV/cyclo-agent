Туториал: агент и язык
Синтаксис самого Cyclorithm — в вики: https://makspv.github.io/cyclorithm/
Здесь — только связка с агентом.

1. Исполняется ОДИН файл (дефолт schedule.cyclo в рабочей директории,
  меняется в Настройках). Остальные .cyclo рядом — модули для use,
  schedule-блок в них запрещён (иначе schedule-in-import).

2. Что исполняется. Задача — это JSON в строке fire:
  0m: JOB.fire() {"cmd": "/bin/echo", "args": ["backup"], "tags": ["backup"], "timeout_s": 1800};
  Этот JSON становится action_attrs события.

3. Виды задач (циклы-обёртки делить по видам: блок вычисляет
  все поля сразу, чужое поле — unknown-field):
  exec: {"cmd": ..., "args": [...], "tags": ["web"], "timeout_s": 10}
  http: {"check": "http", "url": ..., "expect": 200, "contains": "ok", "tags": ["web"], "timeout_s": 10}
  tcp:  {"check": "tcp", "host": ..., "port": ..., "tags": ["web"], "timeout_s": 10}
