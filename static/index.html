Туториал: как писать код
1. Скелет: точка (куда), цикл (кусок времени), корень (сутки).
  point JOB { actions = [fire]; }
  cycle RUN(job) duration = 1m { 0m: JOB.fire() {...}; }
  root_cycle start_time = "2026-01-01T00:00:00", duration = 24h { ... }

2. Строка корня = запуск. Агент исполняет только строки с cmd/check:
  3h: RUN({"cmd": "/bin/echo", "args": ["backup"], "tags": ["backup"], "timeout_s": 1800});

3. Виды задач (циклы-обёртки делить по видам: блок вычисляет
  все поля сразу, чужое поле — unknown-field):
  exec: {"cmd": ..., "args": [...]}
  http: {"check": "http", "url": ..., "expect": 200, "contains": "ok"}
  tcp:  {"check": "tcp", "host": ..., "port": ...}
  общее: "tags": ["web"], "timeout_s": 10.

4. Повторы: repeat N — ровно N стыков; fill — до конца родителя:
  0h: fill HOURLY(...);  [workday(at)] 8h: repeat 11 HOURLY(...);

5. Условия в []: workday(at), day_of_week(at) == 1, свои предикаты:
  pred business_hours(at) = hour(at) >= 9 and hour(at) < 18;

6. Библиотеки: use "libs/x.cyclo" (путь от директории файла);
  в либе только pred/const/таблицы, schedule-блок запрещён
  (иначе schedule-in-import). Чужой файл по URL — кнопкой
  «Вставить по URL» (качает браузер, дальше выбрать файл и сохранить).

7. Длительности: ms s m h d w. Полный живой пример — examples/full.cyclo.
