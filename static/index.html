Расписание


Шпаргалка синтаксиса
schedule "Имя" {
  point JOB { actions = [fire]; }
  cycle RUN(job) duration = 1m {
    0m: JOB.fire() {"cmd": job.cmd, "args": job.args, "timeout_s": job.timeout_s};
  }
  root_cycle start_time = "2026-01-01T00:00:00", duration = 24h {
    3h: RUN({"cmd": "/usr/local/bin/backup.sh", "args": [], "timeout_s": 1800});
    0h: repeat 24 RUN({"cmd": "/opt/jobs/ping.sh", "args": [], "timeout_s": 60});
  }
}
Длительности: ms s m h d w. Условия: [workday(at)], [day_of_week(at) == 1].
Агент исполняет только строки с "cmd". Ошибки покажет «Проверить».
