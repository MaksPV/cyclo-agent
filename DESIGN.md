# DESIGN.md — cyclo-agent admin panel

Дизайн-система веб-морды `cyclo-agent`. Читает дизайн-агент (и человек),
чтобы любой новый экран выглядел как родной **без единого вопроса к автору**.

---

## 0. Манифест

Четыре факта, которые нельзя обойти. Всё остальное — их следствия.

1. **Одна морда — один файл.** `static/index.html`, вшит в бинарь через
   `include_str!`. Никакого фронта, сборки, зависимостей.
2. **Бэкенд отдаёт только JSON** из `/api/*` и на вид не влияет.
3. **Язык интерфейса — русский.** Значения API (`job`, `kind`, `bucket_secs`,
   статусы `ok/fail/timeout/skipped`) не переводятся — совместимость.
4. **Это рабочая панель сисадмина.** Данные важнее картинок. Плотно по
   умолчанию, плотно всегда. Никаких «режимов отображения».

Если изменение нарушает 1–4 — оно отклоняется без обсуждения.

---

## 1. Каркас: VS Code

Структура — как в VS Code: **слева навигация, справа контент**. Один экран,
без вложенных страниц.

```
┌────────────┬──────────────────────────────────────────────────────────────┐
│ cyclo-agent│  Дашборд                             [● здоров] [◐] [выйти]  │
│            ├──────────────────────────────────────────────────────────────┤
│ ▸ Дашборд  │                                                              │
│   События  │  ┌── график ──────┐ ┌── график ──────┐ ┌── график ──────┐   │
│   Редактор•│  │                │ │                │ │                │   │
│   Настройки│  └────────────────┘ └────────────────┘ └────────────────┘   │
│            │                                                              │
│            │  ┌── график ──────┐ ┌── график ──────┐                       │
│            │  │                │ │                │                       │
│            │  └────────────────┘ └────────────────┘                       │
│            │                                                              │
│ admin@host │                                                              │
└────────────┴──────────────────────────────────────────────────────────────┘
   200px                          flex: 1
```

Правила:

- **Сайдбар фиксирован 200px**, не сворачивается, не тянется. Сверху логотип,
  посередине навигация, снизу — кто вошёл.
- **Контент занимает всю оставшуюся ширину.** Никаких `max-width: 1020px`.
  На 1920px дашборд раскладывается в 3–4 колонки, на 1366px — в 3, на
  1024px — в 2, ниже 700px — в 1.
- **Скроллится только контент.** Сайдбар и шапка контента — `position:sticky`.
- **Никаких переключателей плотности.** Плотно — единственный режим.

### Навигация (сайдбар)

Пункты: **Дашборд · События · Редактор · Настройки**. Текст, не иконки.
Активный — цвет `--fg`, слева полоска `2px --accent`, фон
`color-mix(in srgb, var(--fg) 5%, transparent)`.

Несохранённое — точка `•` после названия. Один маркер — баг: он всегда
дублируется строкой-подсказкой под контентом (`#dashdirty`, `#dirty`).

## 2. Токены

Единственный источник правды.

### 2.1. Палитра

```css
:root {
  --bg:     #f4f4f2;   --card:   #ffffff;   --fg:     #1d1d1f;
  --muted:  #6b6b70;   --line:   #dddcd8;   --accent: #2f6fed;
  --ok:     #1a7f37;   --bad:    #cf222e;   --skip:   #6b6b70;
}
[data-theme="dark"] {
  --bg:     #141415;   --card:   #1d1d1f;   --fg:     #e8e8e6;
  --muted:  #a3a3ab;   --line:   #2e2e31;   --accent: #6b9bff;
  --ok:     #3fb950;   --bad:    #f85149;   --skip:   #9a9aa0;
}
```

**Hex напрямую в стилях запрещён.** Только `var(--…)`.

### 2.2. Роли

| Переменная | Где живёт | Где НЕ живёт |
|---|---|---|
| `--bg` | фон контента, фон `#diag`, фон сайтбара **нет** | карточки |
| `--card` | карточки, **сайдбар**, шапка, кнопки, поля, sticky-шапка таблиц | фон контента |
| `--fg` | основной текст, активный пункт сайдбара | подписи |
| `--muted` | подписи, подсказки, неактивные пункты, `stderr`, текст ошибок API | основной текст |
| `--line` | рамки, **оси и сетка графиков** | текст |
| `--accent` | active-полоска сайдбара, primary-кнопка, активный таб, `•`, линия графика, точки графика, crosshair | статусы |
| `--ok` / `--bad` / `--skip` | только статусы и бейджи | всё остальное |

**Правила цвета:**

- Красный — только аварии. Жёлтых варнингов нет и не будет.
- **Один акцент на экран.** `--accent` несёт роль «кликни/смотри сюда».
- Плашка `.pill` своих hex не имеет: `border-radius:2em`, мягкая подложка
  `color-mix(in srgb, <цвет статуса> 12%, transparent)`, рамок нет.

### 2.3. Шрифты

```css
--mono: ui-monospace, SFMono-Regular, Menlo, Consolas, monospace;
```

| Элемент | Шрифт | Размер |
|---|---|---|
| Всё, что не перечислено ниже | system-ui | 14px |
| Таблицы (вкл. время, `cmd`) | system-ui | 13px |
| Редактор `#sched` | `--mono` | 13px |
| `#diag`, `pre.cheat`, tooltip графика | `--mono` | 12px |
| Заголовок контента (breadcrumb) | system-ui | 15px, `font-weight:600` |
| `h2` карточки | system-ui | 1em |
| Подписи, `.chartsub`, `.muted` | system-ui | 0.85em |
| Оси на canvas | `12px system-ui` (рисует код) | 12px |

**Базовый размер — 14px, не 16px.** Плотность. Моно — только код, диагностика,
шпаргалка, тултип графика. Таблицы — пропорциональным.

### 2.4. Retina

Canvas рисуется под `devicePixelRatio`. Логические координаты — по размеру
карточки, физические — `×dpr`. Иначе мылит.

## 3. Компоненты

### 3.1. Сайдбар

```css
.sidebar {
  width: 200px;
  background: var(--card);
  border-right: 1px solid var(--line);
  display: flex; flex-direction: column;
  position: sticky; top: 0; height: 100vh;
```

Три зоны: логотип (`padding:.8em 1em`, `font-weight:600`), навигация
(`flex:1`, `overflow-y:auto`), футер с юзером (`padding:.6em 1em`,

Пункт навигации:

```css

  cursor: pointer;
}
.nav-item.active {
  color: var(--fg); font-weight: 600;
  border-left-color: var(--accent);
  background: color-mix(in srgb, var(--fg) 5%, transparent);

```

### 3.2. Шапка контента

Липкая (`position:sticky; top:0`), фон `--bg` с нижней рамкой `--line`,
`padding:.5em 1.2em`, `display:flex; align-items:center; gap:.8em`.

Слева — заголовок раздела (совпадает с активным пунктом сайдбара).
Справа — бейдж `#health`, кнопка темы `◐`, кнопка «Выйти».

`#health` — `.badge` с состояниями: `…` (запрос), имя расписания (`.ok`),
`ошибка` (`.bad` + пульс 1.6s), `login`, `setup`. Пульсирует только бейдж
ошибки.

### 3.3. Карточка `.card`

```css
.card {
  background: var(--card);
  border: 1px solid var(--line);
  border-radius: .5em;
  padding: .9em 1em;
}
```

Заголовок `h2` — существительное/глагол без воды («Задержка», «Последние
запуски», «Конструктор»). Не «Информация о…».

**Primary-кнопка ровно одна на карточку.** Сообщение результата — `.muted`
под кнопками, не блок, не тост, не модалка.

### 3.4. Таблица

| Свойство | Значение |
|---|---|
| ячейки | `padding:.3em .5em`, 13px, влево |
| рамки | только нижняя `1px --line` |
| числа `.num` | вправо, `tabular-nums`, `nowrap` |
| длинная — `.scroll` | `max-height:30em`, sticky-шапка фон `--card` |
| ховер строки | `color-mix(in srgb, var(--fg) 6%, transparent)` |
| обрезка `stderr` | 100 символов |

Статусы — `.pill`:

```css
.pill { border-radius:2em; padding:0 .6em; border:none; }
.pill.ok              { color:var(--ok);  background:color-mix(in srgb, var(--ok) 12%, transparent); }
.pill.fail, .timeout  { color:var(--bad); background:color-mix(in srgb, var(--bad) 12%, transparent); }
.pill.skipped         { color:var(--skip); background:color-mix(in srgb, var(--skip) 12%, transparent); }
```

Подложка вместо рамки: статусы видно, но они не кричат.

### 3.5. Редактор

**Цель: видеть весь код без прокрутки.** Значит — никакого «карточка,
внутри textarea высотой 320px». Редактор занимает **всю высоту контента**.

```
┌─ toolbar ─────────────────────────────────────────────┐
│ [файл ▾] [Новый] [Удалить]  [URL…] [Вставить по URL] │
├───────────────────────────────────────────────────────┤
│                                                       │
│  textarea#sched — моно 13px                           │
│  flex: 1; min-height: 0; overflow: auto               │
│  высота = вся оставшаяся высота окна                  │
│                                                       │
├─ status ──────────────────────────────────────────────┤
│ 1234 строк · 45 КБ · не сохранено · [Проверить] [▸ Сохранить] │
└───────────────────────────────────────────────────────┘
```

```css
.editor { display: flex; flex-direction: column;
          height: calc(100vh - <высота шапки>); }
.editor textarea {
  flex: 1; min-height: 0;          /* ключ: без min-height:0 flex не даст сжать */
  resize: none; border: none; outline: none;
  padding: .8em 1em;
  font: 13px var(--mono); line-height: 1.5;
  background: var(--bg); color: var(--fg);
}
```

Статусная строка — `padding:.4em 1em`, `border-top:1px --line`, `.muted`,
13px. В ней же справа кнопки «Проверить» и primary «Сохранить». Слева —
факты (строк, размер, флаг «не сохранено»).

`#diag` — сворачиваемый блок под статусной строкой, моно 12px, фон `--bg`,
`max-height:30vh`, скролл внутри.

Правила: «Вставить по URL» качает **браузер**, не сервер (без SSRF).
**Проверка всегда по диску** — при несохранённых правках писать «сначала
Сохранить», а не врать результатом.

### 3.7. График — подробно

График — центральный компонент. Это не «линия на фоне», это **читаемый
инструмент**. Всё ниже обязательно.

**Анатомия:**

```
┌─ .card ─────────────────────────────────────────────────────┐
│ Задержка, мс                                          ● ok  │ ← h2 + статус
│                                                             │
│  120 ┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─  │ ← сетка (--line)
│      │                                            ╱╲         │
│   80 ┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ╱ ─╲ ─ ─ ─  │
│      │                                        ╱      ╲       │
│   40 ┤ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ╱ ─ ─ ─ ─╲ ─ ─  │
│      │                                    ╱             ╲    │
│    0 ┤──────────────────────────────────────────────────    │
│      └──────┬──────────┬──────────┬──────────┬───────        │
│          10:00      10:15      10:30      10:45             │
│                                                             │
│  задержка avg · runs · запусков: 120 | шаг 5с               │ ← .chartsub
└─────────────────────────────────────────────────────────────┘
```

**Оси и сетка:**

- Y-ось: **4–6 тиков** «круглыми» числами (nice numbers: 1/2/5 × 10ⁿ),
  подписи влево (`text-align:right` от оси), единица измерения — в
  заголовке `h2` («Задержка, **мс**», «Размер, **КБ**»). Отступ под ось —
  `48px` слева.
- X-ось: **4–6 тиков** в формате `ЧЧ:ММ`, подписи внизу по центру тика.
  Отступ под ось — `22px` снизу.
- **Горизонтальные линии сетки** на каждом y-тике — цвет `--line`, `1px`,
  без пропусков. Это ключ к читаемости: без сетки на тёмном фоне линия
  висит в вакууме.
- Рамка осей — сплошные линии `--line` по левому и нижнему краю поля.
- Заголовок метрики слева сверху (`.chartsub` в углу карточки или `h2`).

**Данные:**

- Линия — `--accent`, толщина `1.5px`, `lineCap:round`, `lineJoin:round`.
- Пропуски (нет точки) — разрыв линии, не «соединить по прямой».
- Если точек ≥100 — маркеры не рисуются. Если <100 — точки `--accent`
  радиусом `2px` на каждой.
- Все серии (если несколько) — один `--accent`. Разные цвета запрещены:
  различие видно из подписи, цвет лишнего смысла не несёт.

**Crosshair и тултип (hover):**

- `mousemove` по canvas → вертикальная пунктирная линия на x-курсора
  (`--muted`, `1px`, `[3,3]`), горизонтальная пунктирная на y-курсора —
  того же цвета.
- На ближайшей по x точке — круг `--accent` радиусом `4px` с белой обводкой
  `1.5px` (в тёмной теме — `--bg`). «Ближайшая» — по индексу, не по
  расстоянию: точки неравномерны по времени.
- **Тултип** — прямоугольник фон `--card`, рамка `1px --line`, скругление
  `.3em`, `padding:.35em .55em`, моно 12px, две строки:
  ```
  10:23:14
  87 мс
  ```
  Позиционируется рядом с точкой, отзеркаливается у краёв, из canvas не
  вылезает.
- `mouseleave` — crosshair и тултип исчезают.

**События на графике:**

- Если в подписи есть источник событий (запуски), на графике рисуются
  **вертикальные маркеры** тех запусков, что попали в окно: цвет по статусу
  (`--bad` для `fail`/`timeout`, `--ok` для `ok`), `1px`, от оси до верха
  поля. Линия полупрозрачная (`globalAlpha 0.35`), наверху маркера — точка
  `2px` полной яркости. Маркеры не должны спорить с линией данных.
- **Hover по маркеру** (в пределах 4px по x) — тултип показывает событие:
  ```
  10:23:14
  fail · exit 1
  cmd: node scrape.js
  ```
  Не только время и значение, а что это за событие.
- Клик по маркеру — тултип **пинится** (не исчезает при `mouseleave`).
  Повторный клик — снимает пин. Это нужно, чтобы успеть прочитать.
- **Клик по пустому месту графика** — если есть пин, снять его; иначе ничего.

**Пропуски данных и «нет данных»:**

- Нет данных вообще — те же оси (с дефолтными тиками), по центру поля
  текст `нет данных` (`--muted`), **canvas не пустой**.
- Ошибка загрузки — текст сервера дописывается в `.chartsub`, карточка
  на месте, остальные графики рисуются. Один битый не гасит остальных.

**Подпись `.chartsub`** — всегда фактическая, не запрошенная:

```
задержка avg · runs · запусков: 120 | шаг 5с
```

Если сервер укрупнил шаг — в подписи **фактический** шаг. Молча показывать
запрошенное запрещено.

### 3.8. Конструктор дашбордов

Строка таблицы = график. Столбцы **фиксированного порядка, группами**:

| что берём | за какое время и как рисуем | как считаем |
|---|---|---|
| название | окно | способ |
| источник | тип | агрегация |
| значение | | шаг |
| метрика | | |

- «Способ»: `запуски` (точкой в точное время) / `по шагу` (усреднение).
  При `запусках` поля **агрегации и шага `disabled`** — усреднять нечего.
- Новая строка — `+` в первом столбце ghost-строки.
- Кнопки: primary «Сохранить дашборд», обычная «Сбросить».
- **Обновление графиков (таймер 30с, возврат на вкладку) таблицу не
  перерисовывает** и несохранённые строки не сносит. Таблица перерисовывается
  только при загрузке / сбросе / сохранении.

### 3.9. События

Сверху вниз: статус расписания → график задержки (по видимой странице) →
таблица запусков с пагинацией → ближайшие запуски.

- Пагинация: `[‹ назад] стр. N из M (всего K) [вперёд ›]`, селект
  `по [50|100|200]`. Смена фильтра/размера — на страницу 1. Крайние —
  `disabled`.
- **Фильтрация серверная**, страницы честные. Фильтровать постраничные
  данные в браузере запрещено.

### 3.10. Настройки

Две карточки в `.grid2` (`grid-template-columns:1fr 1fr`, ниже 700px —
одна): «Сервер» (директория, файл, дни/строки хранения, параллельность,
lookahead; primary «Сохранить настройки») и «Сессия» (кто вошёл + «Выйти»).
Отдельно — «Смена пароля».

**Подсказка под кнопкой обязательна**: что применится без рестарта (лимиты
хранения), что — после (директория, файл, параллельность).

### 3.11. Вход / первый запуск

Карточка в `#auth` **вместо** приложения. «Вход» (логин+пароль) или
«Первый запуск» (логин+пароль+повтор, пароль ≥8). Ошибка — `alert()` с
текстом сервера. Успех — `refresh()` без перезагрузки.

## 4. Состояния

Каждый экран обязан определить все четыре. Не определил — экран не готов.

| Состояние | Что показываем | Чего не делаем |
|---|---|---|
| Загрузка | `…` в бейдже | скелетонов, спиннеров поверх данных |
| Пусто | оси + «нет данных» / `.muted`-строка в таблице | пустого canvas, пустой карточки без объяснения |
| Ошибка | текст сервера как есть | своих формулировок, «что-то пошло не так» |
| Успех | результат в `.muted` под кнопкой, `#health` обновлён | тостов, галок, анимаций |

**Таксономия ошибок:**

| Источник | Куда |
|---|---|
| 4xx/5xx API | `.muted` под кнопкой той карточки, чей запрос упал |
| Сеть (reject) | то же место, текст как есть |
| Валидация (400) | `.muted` под кнопкой, **русский текст сервера** |
| Вход | `alert()` |
| График | `.chartsub` этого графика, остальные живы |

## 5. Модель обновления

| Событие | Графики | Таблица конструктора | Таблица событий | Формы |
|---|---|---|---|---|
| Открытие вкладки | перерисовать | загрузить | страница 1 | загрузить |
| Таймер 30с | перерисовать | **НЕ трогать** | НЕ трогать | НЕ трогать |
| Смена фильтра | — | — | страница 1 | — |
| «Сбросить» | перерисовать | загрузить | страница 1 | загрузить |
| «Сохранить» | перерисовать | сохранить, обновить | — | сохранить |
| Ошибка запроса | остальные живы | остальные живы | остальные живы | остальные живы |

Правило одной строкой: **несохранённое переживает любые фоновые
обновления.**

### 6.1. Карточка с таблицей и пагинацией

### 6.4. Пустое состояние

Внутри места, где были бы данные. Таблица — `<td colspan=N class="muted">
нет данных</td>`. График — оси + «нет данных» по центру.

## 7. Адаптив

| Что | ≤700px | >700px |
|---|---|---|
| Сайдбар | 160px | 200px |
| `.grid2` (настройки) | 1 колонка | 2 |
| `.dash-grid` | 1 колонка | auto-fill от 340px |
| Редактор | flex-fill, как обычно | flex-fill |
| Таблицы | тянутся, страница не скроллится | то же |
| Canvas | `width:100%`, высота 170px | то же |
| Табы/нав | не переносятся | не переносятся |

Canvas при ресайзе пересчитывает оси (ResizeObserver). Отдельного мобильного
макета графиков нет — DPR + пересчёт осей дают ту же картинку.

Тач: касание = hover (crosshair + тултип). Повторное касание по тому же
месту = снять. Точных попаданий не требуется — действия кнопками, не кликом
по строке.

## 8. Глубина

Система **плоская**. Теней нет нигде.

- Иерархия — только рамками `1px --line` и фоном `--card` над `--bg`.
- Слои: сайдбар → шапка контента (sticky) → карточки → строки таблиц.
- **Модалок, попапов, тостов, дропдаун-меню, тултипов-по-ховеру-на-кнопках
  нет.** Единственный тултип в системе — тултип графика (§3.7), это часть
  графика, не UI-паттерн.
- Canvas — поверх `--card`, без сетки поверх данных.

## 9. Формат значений

Один формат на всю морду. Никаких «здесь покажу покороче, там подлиннее».

| Что | Как | Не как |
|---|---|---|
| Числа ≥1000 | `12 480` (неразрывный пробел) | `12480`, `12,480` |
| Дроби | одна цифра: `87.3` | `87.2891` |
| Проценты | `99.8%` | `99.80%` |
| Байты | `1.2 КБ`, `340 МБ` | `1234567`, `1.2KiB` |
| Длительность | `<1с`, `3с`, `2м 14с`, `1ч 08м` | `0.001s`, `134s` |
| Относительное | `5м назад`, `2ч назад`, `вчера` — только сегодня/вчера | `3 недели назад` |
| Абсолютное | `2026-10-04 14:23:14` через `toLocaleString()` | ISO, UTC, «4 окт» |
| Моно-цифры | `.num` вправо, `tabular-nums`, `nowrap` | по центру, вразнобой |

**Единица измерения — в заголовке, не в ячейке.** Столбец «Задержка, мс»,
а не «12 мс | 87 мс | 203 мс». То же в `h2` графика: «Задержка, **мс**».
Дублировать единицу в каждой ячейке — шум, съедающий ширину.

**Время — всегда локальное браузера.** Панель смотрит человек, UTC не
показываем. На осях графиков — `ЧЧ:ММ`; окно >24ч — `ДД.ММ`; в тултипе
графика — полная дата с секундами. Таймзону нигде явно не подписываем:
это локальная панель.

## 10. Взаимодействие

### 10.1. Копирование

Клик по **техническому** значению копирует его в буфер: `ID`, `cmd`, путь,
URL, текст в `#diag`. Отклик — на 1с фон `color-mix(in srgb, var(--accent)
10%, transparent)`, без иконок и тултипов «Скопировано».

Не делать: иконку копирования рядом с каждой ячейкой (шум), копирование
обычного текста, всплывашку «скопировано» (тостов в системе нет).

### 10.2. Сортировка

- Только **серверная**. Клиентская сортировка постраничных данных запрещена
  — та же логика, что фильтры: страницы должны быть честными.
- Клик по `<th>` с серверной сортировкой: `▲`/`▼` рядом с подписью, цвет
  `--accent`. По умолчанию сортировки нет, порядок задаёт сервер.
- Сортировка живёт в URL (`?sort=ts&dir=desc`), не в `localStorage`. F5
  и «назад» работают.

### 10.3. Фильтры

- Над таблицей, в `.row`. Всегда видимы. Не сворачиваются, не в поповере.
- Применяются **сразу**, кнопки «Применить» нет — сервер успевает, дизайн
  плотный.
- Смена любого фильтра — **сброс на страницу 1**.
- «Сбросить фильтры» — только если фильтров больше одного.
- Фильтр — часть URL (`?status=fail`).

### 10.4. Клавиатура и фокус

- `:focus-visible` — обводка `2px --accent`, `outline-offset:2px`. Мышиный
  фокус невидим (`:focus:not(:focus-visible)` без обводки).
- Tab-порядок — естественный, сверху вниз. `tabindex` не ставить, кроме
  `-1` для программных целей (пин графика, фокус в редактор).
- `Esc` — снять пин с графика, закрыть `details` шпаргалки, снять фокус.
- `Ctrl/Cmd+S` в редакторе — «Сохранить» (с `preventDefault`).
- Строки таблиц **не фокусируются**: действия — кнопками, не Enter по
  строке. Это не список файлов, это обзор.

## 11. Опасное и несохранённое

### 11.1. Подтверждение

- Опасное действие («Удалить» файл, «Выйти») — через `confirm()` с русским
  текстом: «Удалить `main.cyc`? Отменить нельзя.» Не своя модалка, не второй
  клик, не ввод имени.
- Кнопка `button.danger`: контур `--bad`, фон `--card`, текст `--bad`.
  Primary-стиль для опасного запрещён.
- Опасная кнопка **никогда не первая** в ряду. Сначала обычная/primary,
  потом опасная.
- После — сообщение в `.muted` под кнопкой и перезагрузка списка.

### 11.2. Несохранённое

- Уход со страницы (close, F5, back) с несохранённым — `beforeunload`,
  браузерный диалог. Своё окно не рисовать.
- Переключение вкладок **внутри морды** — без диалога: данные остаются в
  DOM, возврат на вкладку сохраняет правки. Точка `•` напоминает, что не
  сохранено.
- Автосохранения нет. Сохранение — всегда явная кнопка.

## 12. Фон и переполнение

### 12.1. Фоновые запросы

- Запрос по кнопке — кнопка `disabled`, **текст не меняется**. Спиннер не
  рисовать, «Сохраняю…» не писать.
- Фоновый (таймер 30с, обновление графика) — **визуально никак**, кроме
  обновившейся подписи. Никаких «обновлено 3с назад», никаких анимаций.
- Ошибка фонового запроса **не всплывает поверх** уже показанного. Пишется
  в `.muted`/`.chartsub` того места, чьи данные не пришли, остальные живы.

### 12.2. Обрезка

- Обрезка — **всегда 100 символов** для «потоковых» полей: `stderr`, `cmd`,
  пути. Таблица — обзор; детали — в тултипе графика или в пиннутом тултипе.
- Обрезанное — `…` в конце, полный текст в `title` (браузерный, не свой).
- Ячейка **не переносится**: `white-space:nowrap` + обрезка. Длинная строка,
  раздувающая строку таблицы, — баг вёрстки.
- Числа **не обрезаются никогда**. Не влезают — сигнал к другой вёрстке,
  не к обрезке.

## 13. Микротексты и доступность

### 13.1. Микротексты

- Кнопки: глагол в инфинитиве — «Сохранить», «Проверить», «Сбросить».
  Не «ОК», не «Отправить», не «Готово».
- Заголовки карточек: существительное («Расписание», «Запуски») или
  короткий глагол («Конструктор»).
- Подписи полей: существительное, без двоеточия в `<label>`.
- Сообщение результата — предложение с точкой: «Настройки сохранены.»,
  «Сначала сохраните файл.» Не «Готово!», не «Успех».
- Пустое состояние — «нет данных», максимум три слова. Не «Здесь пока
  ничего нет. Добавьте первое событие.»
- Ошибки сервера — как есть. Своих формулировок не придумываем.
- Никаких «Пожалуйста», «Упс», «Ой». Инструмент не извиняется.

### 13.2. Доступность (минимум)

- Контраст `--fg`/`--bg` — ≥4.5:1 (в палитре соблюдено), `--muted`/`--card`
  — ≥3:1 для подписей.
- Всё интерактивное — `<button>` или `<a>`. `<div onclick>` запрещён.
- `<table>` с `<thead>` и `<th scope="col">`. Не `div`-таблица.
- Canvas-график — `role="img"` и `aria-label` с сутью: «график задержки,
  120 точек, от 0 до 120 мс».
- `aria-live` — только у `#health`. Остальное по требованию, не поголовно.
