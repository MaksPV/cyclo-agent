# DESIGN.md — cyclo-agent admin panel

Дизайн-документ для веб-морды `cyclo-agent`. Читает дизайн-агент (и человек),
чтобы любой новый экран выглядел как родной.

Факты, от которых нельзя отступать: вся морда — **один файл**
`static/index.html` (вшит в бинарь через `include_str!`, отдельного фронта,
сборки и зависимостей нет); бэкенд отдаёт только JSON из `/api/*` и на вид
не влияет. Язык интерфейса — русский. Это **рабочая панель сисадмина**,
а не лендинг: данные важнее картинок, всё на одном экране, ничего лишнего.

## 1. Visual Theme & Atmosphere

- Плотная светлая панель по умолчанию, тёмная — по переключателю `◐` в шапке
  и по `prefers-color-scheme` при первом визите (выбор хранится
  в `localStorage.theme`).
- Настроение: спокойно-инструментальное. Нет hero-блоков, иллюстраций,
  маркетинговых цветов. Один акцент на всё.
- Плотность высокая: таблицы 13px, карточки друг под другом без воздуха
  про запас. Пустое состояние — не пустота, а рамка осей + текст
  «нет данных» прямо на графике.
- Дух-ориентиры из коллекции: Sentry (плотный тёмный дашборд мониторинга),
  Linear (минимум хрома, точность), PostHog (таблицы прежде всего).

## 2. Color Palette & Roles

Все цвета — только через CSS-переменные, hex напрямую в стилях запрещён.

| Переменная | Светлая | Тёмная | Роль |
|---|---|---|---|
| `--bg` | `#f4f4f2` | `#141415` | фон страницы, фон поля `#diag` |
| `--card` | `#ffffff` | `#1d1d1f` | карточки, шапка, кнопки, поля ввода |
| `--fg` | `#1d1d1f` | `#e8e8e6` | основной текст |
| `--muted` | `#6b6b70` | `#a3a3ab` | подписи, подсказки, неактивные табы, `stderr` |
| `--line` | `#dddcd8` | `#2e2e31` | рамки карточек/полей/таблиц, оси графиков (та же переменная) |
| `--accent` | `#2f6fed` | `#6b9bff` | primary-кнопки, подчёркивание активного таба, маркер `•` несохранённого, ховер рамок, линия графика |
| `--ok` | `#1a7f37` | `#3fb950` | статус `ok`, бейдж здоровья |
| `--bad` | `#cf222e` | `#f85149` | статусы `fail`/`timeout`, бейдж ошибки, текст ошибок |
| `--skip` | `#6b6b70` | `#9a9aa0` | статус `skipped` (сознательно равен светлому `--muted`: пропуск — не авария) |
| — | — | — | плашка `.pill`: скругление `2em`, рамка `currentColor`, своих hex нет |

Правила:

- Красным — только аварии (`fail`, `timeout`, битое расписание, текст ошибок
  API). Варнингов жёлтым в системе нет — не вводить.
- Акцент один (`--accent`): primary-кнопка, активный таб, линия графика,
  маркеры несохранённого, фокус с клавиатуры. Два акцента рядом запрещены.
- Кнопки в тупике (крайние страницы) — `disabled`, а не кликабельная пустышка.
- Опасное действие («Удалить» файл) — контур `button.danger` цветом `--bad`,
  обычные и primary его не касаются.
- Плотность — переключатель в шапке (`плотно`/`свободно`,
  `data-density`, запоминается): свободно даёт воздух строкам и карточкам.
- Графики рисуются под плотность пикселей (`devicePixelRatio`, координаты
  логические 940×170) — на retina не мылят.
- Бейдж ошибки пульсирует (`pulse 1.6s`), остальные бейджи статичны.
- Серии графиков всех — `--accent`; разные цвета сериям не давать
  (способ уже виден из подписи, цвет лишнего смысла не несёт).

## 3. Typography Rules

| Элемент | Шрифт | Размер |
|---|---|---|
| Текст, кнопки, поля | `system-ui, -apple-system, sans-serif` (наследование через `font:inherit`) | базовый 16px, таблицы `13px`, `.muted` `0.85em` |
| Время, `cmd`, теги — в таблицах | тот же системный (таблицы не моно) | `13px` |
| Редактор `#sched`, диагностика `#diag`, шпаргалка `pre.cheat` | `--mono`: `ui-monospace, SFMono-Regular, Menlo, Consolas, monospace` | `13px` редактор, `12px` диагностика/шпаргалка |
| Заголовок шапки `h1` | системный | `1.1em`, `margin:0 auto 0 0` (бейджи справа) |
| Заголовки карточек `h2` | системный | `1em`, `margin:.2em 0 .7em` |
| Подписи графиков `.chartsub`, пагинация `#rpage` | системный через `.muted` | `0.85em` |
| Подписи осей на canvas | `11px system-ui, sans-serif` (рисуется кодом, не CSS) | 11px |

Правила:

- Моноширинный — только там, где важна посимвольная точность: код,
  диагностика, шпаргалка. Таблицы событий — пропорциональным.
- Время в таблицах — `toLocaleString()`, на осях графиков — `ЧЧ:ММ`.
- Текст ошибок API показывать как есть (сервер уже пишет по-русски),
  не перефразировать.

## 4. Component Stylings

### Шапка

Липкая (`position:sticky; top:0`), фон `--card`, нижняя рамка `--line`,
`padding:.7em 1.2em`. Слева `h1 cyclo-agent`, справа: бейдж `#health`
(`…` / имя расписания / `ошибка` / `login` / `setup`), кнопка темы `◐`.

### Бейдж `.badge`

`font-size:.8em`, скругление `2em`, рамка `--line`, текст `--muted`.
Модификаторы: `.ok` (цвет+рамка `--ok`), `.bad` (`--bad`).

### Табы `nav.tabs`

Кнопки без рамки, нижнее подчёркивание `2px transparent`, неактивные —
`--muted`. Активная: цвет `--fg`, подчёркивание `--accent`, `font-weight:600`.
Несохранённое: точка `•` в тексте таба (`Дашборд •`, `•` у Редактора)
плюс строка-подсказка (`#dashdirty`, `#dirty`) — оба маркера всегда парой.

### Карточка `.card`

Фон `--card`, рамка `1px --line`, скругление `.6em`, `padding:1em`,
`margin-bottom:1em`. Заголовок `h2` — что это (всегда глагол/существительное:
«Последние запуски», «Конструктор», «Расписание»).

### Таблицы

`border-collapse`, `width:100%`, ячейки `padding:.35em .5em`, `13px`,
только нижняя рамка `--line`, выравнивание влево. Числа (`exit`, `мс`) —
класс `.num`: вправо + `tabular-nums`, без переноса. Длинные таблицы
(запуски, конструктор) живут в `.scroll` (`max-height:30em`, скролл внутри),
шапка липкая (`position:sticky; top:0`, фон `--card`). Ховер строки —
подсветка `color-mix(in srgb, var(--fg) 6%, transparent)` (новых токенов нет).
Статус — плашка `.pill` (скругление `2em`, рамка `currentColor`):

### Пагинация (таблица событий)

Строка `.row` под таблицей: `[‹ назад] стр. N из M (всего K) [вперёд ›]`.
Размер страницы — селект `по [50|100|200]` рядом с фильтром статуса.
Смена фильтра/сразмера сбрасывает на страницу 1. Мини-график задержки
рисуется по видимой странице («что вижу, то и график»).

### График (canvas)

Атрибуты `width=940 height=170`, CSS `width:100%; height:170px`.
Всегда: название метрики слева сверху, рамка осей цветом `--line`,
тики `min/max` слева, время по низу. Нет данных — те же оси + «нет данных»
по центру поля (пустого canvas не бывает). Подпись под графиком:
`метрика агрегация · источник · запусков: N | шаг Xс`. Ошибка загрузки —
текст сервера дописывается в ту же подпись, карточка остаётся на месте,
остальные графики рисуются (один битый не гасит остальных).

### Конструктор дашбордов

Строка таблицы = график. Порядок столбцов фиксированный, группами:
что берём (название, источник, значение, метрика) → за какое время и как
рисуем (окно, тип) → как считаем (способ, агрегация, шаг).
Столбец «способ»: `запуски` (каждый запуск точкой в точное время) /
`по шагу` (усреднение). При «запусках» поля агрегации и шага `disabled`
(серые, не трогаются) — усреднять нечего. Новая строка — кнопка `+`
в первом столбце ghost-строки. Кнопки: primary «Сохранить дашборд»,
«Сбросить» (перечитать с сервера). Обновление графиков (вкладка, таймер
30с) таблицу не перерисовывает и несохранённые строки не сносит.

### Редактор

Селект файла + «Новый»/«Удалить» + поле URL + «Вставить по URL»
(качает **браузер**, сервер файл не трогает — без SSRF).
`textarea#sched` моно `13px`, высота `320px`. Кнопки: «Проверить»,
primary «Сохранить». Диагностика `#diag`: моно `12px`, фон `--bg`.
Правило: проверка всегда по диску (главный файл), при несохранённых
правках писать «сначала Сохранить», а не врать результатом.
Шпаргалка — `details` «Туториал: агент и язык», только связка с агентом,
синтаксис языка — ссылкой на вики первым пунктом.

### Настройки

Две карточки (`grid2`): «Сервер» (редактируемые поля: директория, файл,
дни/строки хранения, параллельность, lookahead; кнопка primary
«Сохранить настройки») и «Сессия» (кто вошёл + «Выйти»). Отдельно карточка
«Смена пароля». Подсказка под кнопкой: что применится без рестарта
(лимиты хранения), что — после (директория, файл, параллельность).

### Вход / первый запуск

Карточка в `#auth` вместо приложения: «Вход» (логин+пароль) или
«Первый запуск» (логин+пароль+повтор, пароль ≥8). Ошибка — `alert()`
с текстом сервера. Успех — `refresh()` без перезагрузки страницы.

## 5. Layout Principles

- `main`: `max-width:1020px`, по центру, `padding:1.2em`. Шире не делать:
  таблицы 13px на широком экране расползаются.
- Порядок вкладки «События» сверху вниз: статус расписания → задержка →
  запуски с пагинацией → ближайшие. Важное (живо ли) раньше истории.
- `.row`: `display:flex; gap:.6em; align-items:center; flex-wrap:wrap` —
  стандартный ряд для фильтров и кнопок.
- `.grid2`: две равные колонки в настройках, ниже `700px` — одна.
- Кнопки действий парами: обычная + primary справа/сразу после
  («Сбросить» + «Сохранить», «Проверить» + primary «Сохранить»).
  Primary — ровно одна на карточку, это главное действие.
- Сообщения (`#cfgmsg`, `#pwmsg`, `#dashmsg`, `#diag`) — `.muted` под
  кнопками, текст результата операции, а не новый блок.

## 6. Depth & Elevation

- Плоская система: глубина только рамками `1px --line`, теней нет нигде.
- Иерархия: шапка (липкая, поверх всего) → карточки → строки таблиц
  (только нижние рамки). Модалок, попапов, тостов нет — сообщения
  пишутся в строки под кнопками, ошибки входа — `alert()`.
- Canvas рисуется поверх фона `--card`; сетки поверх данных нет,
  только рамка осей.

## 7. Do's and Don'ts

| Делать | Не делать |
|---|---|
| Цифры честные: фактический шаг — в подпись графика, время — точное | Молча укрупнять/пересчитывать и показывать запрошенное |
| Несохранённое переживает обновления (таблица — только при загрузке/сбросе/сохранении) | Перерисовывать конструктор по таймеру |
| Пусто = оси + «нет данных»; битый график = текст ошибки в подписи, остальные живы | Пустой canvas, один битый гасит всех |
| Левый ввод — 400 с русским текстом, фронт показывает текст сервера | Тихие дефолты вместо ошибки; перефразировать ошибки сервера |
| Серверный фильтр + `total` для страниц (страницы честные) | Фильтровать постраничные данные в браузере |
| Проверки по диску, при правках — «сначала Сохранить» | Проверять несохранённый текст и выдавать за результат |
| Один accent, статусы по цветам из §2 | Новые цвета «для красоты», жёлтые варнинги |
| Русские подписи Columns: задача/тип/шаг, не джоба/вид/бакет | Жаргон и англицизмы в подписях (значения API `job/kind/bucket_secs` при этом не переименовывать — совместимость) |

## 8. Responsive Behavior

- Точка `700px`: `.grid2` схлопывается в одну колонку. Таблицы тянутся
  (`width:100%`), горизонтального скролла страниц нет — таблицы сами
  по себе не скроллятся, режутся только длинным `stderr` (100 символов).
- Canvas: `width:100%` тянется под карточку, высота фиксирована `170px`;
  оси пересчитываются кодом при каждой отрисовке, отдельный мобильный
  макет графиков не нужен.
- Шапка липкая на любой ширине; табы не переносятся (4 коротких слова).
- Отдельных тач-таргетов не вводить: кнопки и так `padding:.35em .9em`,
  таблица не требует точных попаданий (действия — кнопками, не кликом
  по строке).

Готовые промпты:

  классами ok/fail/timeout/skipped, длинные поля резать до 100 символов»
- «Новый график — как в §4: оси цветом --line, подпись
